## 备注

- **zkcrypto 报告 0 个问题**: 这是正确的。它是一个纯 Rust 项目，100% 被归类为安全区域。工具正确识别出不存在 FFI 边界违规。
- **wasmtime 有 44 个问题但 0 个违规**: 问题来自非 ptr_lifetime 的分析 pass (taint、ffi_boundary、callback_escape)。这些是信息性的，不是确认的违规。
- **curl/sqlite3 是纯 C 项目**: 它们贡献了 548 个问题中的 340 个 (62%)，但不在 OmniScope 的核心 FFI 聚焦范围内。它们展示了工具的通用内存安全能力。
- **精确度估计**: 基于 subtle_unsafe_rs 的手动验证 (100%) + curl/sqlite3 的抽样验证 (~85%)。完整手动验证待完成。

## 复现

```bash
# 构建
zig build

# 对单个文件运行
./zig-out/bin/omniscope path/to/your/file.ll

# 带详细输出运行
./zig-out/bin/omniscope --verbose path/to/your/file.ll
```
