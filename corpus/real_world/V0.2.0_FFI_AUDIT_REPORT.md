> **定位**: OmniScope 是 **FFI/Unsafe 边界安全Static Analysis工具**

### 1.2 R7.0 架构变更说明

本次更新引入 **Zone-First 门控架构**，将 Zone Classification 从"事后统计"提升为"事前门控"：

```
Before (白名单地狱):
  函数 → NoiseReduction(20规则) → FPWhitelist(18条) → ffi_noise_filter(15条)
       → ffi_zone_check(109条) → 🔴 报告? → 大量 FP (2,924)

After (Zone-First):
  函数 → classifyFunctionFromLLVM() → ZoneKind
       ├─ .safe / .runtime_internal → ❌ 跳过（替代 ~100 条白名单）
       ├─ .unknown → 低置信度分析
       └─ .ffi / .unsafe → 全量高置信度分析 + zone-aware callee 过滤
       结果: 1,169 Issues，TP 率 >90%
```
