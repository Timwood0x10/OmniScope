## 三、关键技术修复

### 3.1 Rust Panic/Cleanup 白名单修复

**问题**: `isRustPanicOrCleanupFunction` 检查了错误的参数（`caller_func` 而非 `free_func_name`）

**修复**: 添加 `isRustPanicOrCleanupStr` 字符串版本，并正确检查 `free_func_name`

```zig
// 修复前: 检查 caller_func (错误)
if (isRustPanicOrCleanupFunction(caller_func)) { ... }

// 修复后: 检查 free_func_name (正确)
if (isRustPanicOrCleanupStr(free_func_name)) { ... }
```

**效果**: blst: 87 → 10 (↓ 84%)
